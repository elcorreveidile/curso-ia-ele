## 🎯 ¿QUÉ ES GITHUB Y POR QUÉ LO USAMOS?

### GitHub es:
- Una plataforma para alojar proyectos y archivos
- Un sistema de control de versiones (guarda el historial de cambios)
- Una herramienta de colaboración profesional
- **¡Gratis para uso educativo!**

### En este curso, tu repositorio GitHub será:
📁 **Tu portafolio digital** - Todas las tareas que crearás durante el curso  
📝 **Tu espacio de entregas** - Donde subirás tus actividades para evaluación  
🌐 **Tu web personal** - La base para crear tu sitio web final del curso  

### Ventajas de usar GitHub:
✅ Aprenderás una herramienta usada por profesionales worldwide  
✅ Tendrás un portafolio digital para compartir con empleadores/as  
✅ Tu trabajo estará seguro y organizado en un solo lugar  
✅ Podrás colaborar con otras personas en el futuro

## 1️⃣ CREAR CUENTA EN GITHUB

### Paso 1: Acceder a GitHub

1. Abre tu navegador (Chrome, Firefox, Safari, Edge)
2. En la barra de direcciones, escribe: **https://github.com**
3. Pulsa **Enter**

### Paso 2: Iniciar el registro

1. En la página principal de GitHub, busca el botón verde que dice **"Sign up"** (o "Registrarse" si está en español)
2. Haz clic en **"Sign up"**

> **💡 NOTA:** Si la página aparece en inglés y prefieres español:
> - Ve al final de la página
> - Busca "Language" o "Idioma"
> - Selecciona "Español"

### Paso 3: Completar el formulario

Verás un formulario con 4 campos. Llénalo así:

**Campo 1: Email address (Correo electrónico)**
- Escribe tu correo electrónico personal o institucional
- Asegúrate de que sea un correo que revises regularmente
- Ejemplo: `tu.nombre@correo.com`

**Campo 2: Password (Contraseña)**
- Crea una contraseña segura
- Debe tener al menos 15 caracteres O 8 caracteres con números y letras
- Ejemplo: `CursoELE2026!` (usa una que puedas recordar)
- Guárdala en un lugar seguro

**Campo 3: Username (Nombre de usuario)**
- Este será tu identificador público en GitHub
- **Sugerencia:** Usa tu nombre o algo profesional
- Ejemplos: `maria-garcia-ele`, `juanprofesor`, `anaele2026`
- Si el nombre que quieres está ocupado, GitHub te sugerirá alternativas

**🚨 IMPORTANTE:** Tu nombre de usuario **no se puede cambiar** después (fácilmente). Elige algo que te identifique profesionalmente.

**Campo 4: Continue (Continuar)**
- Haz clic en el botón "Continue" cuando hayas completado los 3 campos anteriores

### Paso 4: Personalización (opcional)

GitHub te preguntará sobre tus intereses. 

> **Recomendación:** 
> - Puedes saltar esto haciendo clic en **"Skip personalization"** (Omitir personalización)
> - O selecciona "Education" (Educación) si está disponible

### Paso 5: Verificar email (muy importante)

1. Revisa tu bandeja de entrada de correo
2. Busca un email de **GitHub** (asunto: "[GitHub] Please verify your email address" o similar)
3. Ábrelo y haz clic en el botón **"Verify email address"** (Verificar dirección de email)

> **⚠️ NO PUEDES CONTINUAR sin verificar tu email.** Revisa también tu carpeta de spam/correo no deseado si no ves el email en 5 minutos.

---

## 2️⃣ CONFIGURAR TU PERFIL (opcional pero recomendado)

Una vez verificado tu email:

### Paso 1: Añadir tu nombre completo

1. En la esquina superior derecha, verás tu foto o iniciales → haz clic
2. Selecciona **"Your profile"** (Tu perfil) o **"Settings"** (Configuración)
3. Si vas a Settings, busca el campo **"Full name"** (Nombre completo)
4. Escribe tu nombre real: `María García`, `Juan Pérez`, etc.
5. Haz clic en **"Save"** o **"Update profile"** (Guardar/Actualizar perfil)

### Paso 2: Añadir una bio breve (opcional)

1. En el mismo lugar, busca el campo **"Bio"** (Biografía)
2. Escribe algo breve y profesional:
   - Ejemplo: `Profesora de ELE | UGR 2026`
   - Ejemplo: `Docente de español | Estudiante de curso IA-ELE`
3. Guarda los cambios

> **💡 NOTA:** Esto es opcional pero recomendado. Tu perfil será visible públicamente, así que manténlo profesional.

### Paso 3: Añadir una foto (opcional)

1. En tu perfil, verás un icono de cámara o **"Upload photo"** (Subir foto)
2. Selecciona una foto profesional tuya
3. Recorta la imagen si es necesario
4. Guarda los cambios

---

## 3️⃣ CREAR TU PRIMER REPOSITORIO

Ahora vamos a crear el repositorio del curso. **Este será tu espacio de trabajo principal**.

### ¿Qué es un repositorio?

Un **repositorio** (o "repo") es como una carpeta donde guardarás todos los archivos de un proyecto. En este caso, será tu carpeta del curso.

### Paso 1: Ir a la página de crear repositorio

1. En la esquina superior derecha, haz clic en el **+** (más) junto a tu foto
2. En el menú desplegable, selecciona **"New repository"** (Nuevo repositorio)

### Paso 2: Configurar el repositorio

Verás un formulario. Llénalo así:

**Repository name (Nombre del repositorio):**
- Escribe: **`curso-ia-ele`**
- Este será el nombre de tu carpeta del curso
- **Importante:** Usa minúsculas y guiones (no espacios)

**Description (Descripción):**
- Escribe: `Portafolio del curso IA para la enseñanza de ELE`
- O cualquier descripción breve que describa qué contiene

**Public vs Private (Público vs Privado):**
- **Selecciona: 🔒 Private** (Privado)
- Esto significa que solo tú puedes verlo (y el formador cuando le compartas el enlace)
- **NO marques "Add a README file"** por ahora (lo haremos más tarde)

### Paso 3: Crear el repositorio

1. Revisa que todo esté correcto
2. Haz clic en el botón verde **"Create repository"** (Crear repositorio)
3. ¡Felicidades! 🎉 Has creado tu primer repositorio

> **¿Qué verás ahora?**
> - Una página con el nombre de tu repositorio
> - Un mensaje de bienvenida
> - Opciones para añadir archivos
> - La URL de tu repositorio (guárdala, la necesitarás)

---

## 4️⃣ SUBIR TU PRIMERA TAREA

Ahora vamos a subir tu primera tarea al repositorio. **Este es el proceso que repetirás para todas las entregas.**

### Paso 1: Crear un archivo nuevo

1. En tu repositorio, busca el enlace **"creating a new file"** (crear un nuevo archivo)
2. Haz clic en **"Add file"** → **"Create new file"** (Añadir archivo → Crear nuevo archivo)

### Paso 2: Nombrar el archivo

1. Verás un campo para el nombre del archivo
2. Escribe el nombre de tu primera tarea:
   - Ejemplo: `modulo-1-declaracion-etica.md`
   - Ejemplo: `modulo-2-asistente.md`
3. La extensión **`.md`** significa "Markdown" — un formato de texto simple

### Paso 3: Escribir tu tarea

1. En el área grande de texto, escribe o pega el contenido de tu tarea
2. Puedes formatear el texto con:
   - `# Título` para títulos grandes
   - `## Subtítulo` para subtítulos
   - `- Lista` para listas con viñetas
   - `**negrita**` para texto en negrita

### Paso 4: Guardar los cambios

1. Baja hasta la parte inferior de la página
2. En el campo **"Commit new file"** (Confirmar nuevo archivo):
   - Primera línea: Escribe un título breve
     - Ejemplo: `Subir Módulo 1 - Declaración ética`
   - Segunda línea (opcional): Escribe una descripción más larga
     - Ejemplo: `Mi declaración personal de uso ético de la IA`
3. Selecciona **"Commit directly to the main branch"** (Confirmar directamente a la rama principal)
4. Haz clic en el botón verde **"Commit changes"** (Confirmar cambios)

> **🎉 ¡Felicidades!** Has subido tu primera tarea a GitHub.

## 5️⃣ COMPARTIR TU REPOSITORIO CON EL FORMADOR

Cuando quieras entregar una tarea para evaluación, tienes **dos opciones**:

---

### 🔵 OPCIÓN A: Compartir el enlace en la plataforma del curso (MÁS SENCILLO)

Esta es la forma más directa. Simplemente comparte la URL de tu repositorio.

#### Paso 1: Copiar la URL de tu repositorio

1. En tu repositorio, copia la URL de la barra de direcciones del navegador
   - Ejemplo: `https://github.com/tu-usuario/curso-ia-ele`
2. Guárdala en un documento de notas

#### Paso 2: Compartir en la plataforma del curso

1. Ve a la tarea correspondiente en la plataforma del curso
2. En el campo de entrega, pega la URL de tu repositorio
3. Añade una nota con el nombre del archivo específico si hay varios:
   - Ejemplo: `Mi repositorio: https://github.com/maria-garcia/curso-ia-ele`
   - Ejemplo: `Archivo: modulo-1-declaracion-etica.md`

#### Paso 3: El formador te pedirá acceso

> **⚠️ IMPORTANTE:** Como tu repositorio es **Private**, cuando el formador abra el enlace, GitHub le mostrará un mensaje:
> - "Repository not found" o "You need permission to access this repository"
> - Entonces él te solicitará acceso a través de GitHub
> - **Tú recibirás un email** de GitHub con el asunto: "[GitHub] Access requested to your repository"
> - Abre el email y haz clic en **"View request"** (Ver solicitud)
> - Luego haz clic en **"Approve request"** (Aprobar solicitud)
> - ¡Listo! El formador ya podrá ver tu repositorio

---

### 🟢 OPCIÓN B: Añadir al formador como colaborador (MÁS RÁPIDO A LARGO PLAZO)

Esta opción requiere un paso extra al principio, pero es más rápida para las siguientes entregas.

#### Paso 1: Ir a Configuración del repositorio

1. En tu repositorio, haz clic en la pestaña **"Settings"** (Configuración) arriba
2. En el menú lateral, busca y haz clic en **"Collaborators and teams"** (Colaboradoras y equipos)
   - O simplemente **"Collaborators"** (Colaboradoras)

#### Paso 2: Añadir al formador

1. Haz clic en el botón **"Add people"** (Añadir personas)
2. En el campo que aparece, escribe: `elcorreveidile`
3. Selecciona el usuario cuando aparezca
4. Haz clic en **"Add repository collaborator"** (Añadir colaborador al repositorio)
5. **Confirmar:** Aparecerá un mensaje confirmando que se ha enviado una invitación

#### Paso 3: El formador acepta la invitación

1. El formador recibirá un email de invitación
2. Cuando acepte, ya tendrá acceso permanente a tu repositorio
3. **Ventaja:** Para futuras entregas, no necesitarás aprobar nada — solo pega el enlace en la plataforma del curso

---

### 📋 RESUMEN: ¿QUÉ OPCIÓN ELEGIR?

| Opción | Ventaja | Cuándo usarla |
|--------|---------|---------------|
| **Opción A** (Compartir enlace) | Más simple, solo copias y pegas | Primera entrega o si no te sientes cómoda/o con GitHub |
| **Opción B** (Colaboradora) | Más rápido a largo plazo, solo una vez | Si quieres ahorrar tiempo en futuras entregas |

> **💡 Recomendación:** Usa la **Opción A** para la primera entrega. Si te sientes cómoda/o con GitHub, puedes usar la **Opción B** después.

## 7️⃣ GLOSARIO DE TÉRMINOS DE GITHUB

| Término | Traducción | Qué significa |
|---------|------------|---------------|
| **Repository** | Repositorio | Carpeta donde guardas archivos de un proyecto |
| **Private** | Privado | Solo tú puedes verlo (o personas que autorices) |
| **Public** | Público | Cualquiera en internet puede verlo |
| **Commit** | Confirmar | Guardar cambios en el historial |
| **Branch** | Rama | Versión paralela de un proyecto (no usaremos esto ahora) |
| **README** | LÉEME | Archivo de información principal del repositorio |
| **Collaborator** | Colaboradora | Persona con permiso para editar tu repositorio |
| **Star** | Estrella | Marcar un repositorio como favorito |
| **Fork** | Bifurcar | Crear una copia de un repositorio de otra persona |
| **Pull request** | Solicitud de extracción | Proponer cambios a un proyecto (no usaremos ahora) |

## 8️⃣ PREGUNTAS FRECUENTES (FAQ)

### ❓ ¿Tengo que pagar algo?

**No.** GitHub es gratis para uso personal y educativo. No necesitas tarjeta de crédito.

### ❓ ¿Puedo cambiar mi nombre de usuario después?

**No fácilmente.** Elige bien tu nombre de usuario desde el principio. Si realmente necesitas cambiarlo, tendrás que crear una cuenta nueva.

### ❓ ¿Qué pasa si olvido mi contraseña?

1. En la página de login de GitHub, haz clic en **"Forgot password"** (¿Olvidaste tu contraseña?)
2. Escribe tu email
3. Recibirás instrucciones para crear una nueva contraseña

### ❓ ¿Puedo usar mi correo institucional (UGR)?

**Sí.** De hecho, es recomendable usar un correo que revises regularmente.

### ❓ ¿Tengo que descargar algo?

**No.** Solo usaremos la versión web de GitHub. No necesitas descargar ningún software.

### ❓ ¿Puedo acceder desde mi móvil?

**Sí.** GitHub tiene una app móvil (iOS y Android). Sin embargo, **recomendamos usar un ordenador** para crear tu repositorio y subir tareas, ya que es más fácil.

### ❓ ¿Mis compañeros/as verán mis tareas?

**No.** Como tu repositorio es **Private**, solo tú y el formador podréis verlo (una vez que le des acceso).

### ❓ ¿Qué pasa si subo el archivo equivocado?

**No pasa nada.** Puedes borrar archivos y subir nuevos cuantas veces necesites. GitHub guarda el historial, así que nunca perderás nada.

### ❓ ¿Necesito saber programar?

**No.** GitHub se creó para programadores/as, pero ahora se usa para muchas cosas: escritura, documentación, portfolios, educación. No necesitas saber programar para este curso.
